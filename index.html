Perguntas Frequentes

Tudo o que você precisa saber antes de começar.

O Mestre do PC é seguro?

+
Sim! A segurança é o pilar central do projeto. Toda operação é validada contra uma whitelist estrita (allowed-operations.json) antes de ser executada. Comandos livres gerados por IA são sempre recusados.

Preciso de internet para usar?

+
Não! O Mestre do PC é 100% local-first. A interface, o launcher e o servidor MCP rodam na sua máquina. A IA via Ollama também funciona localmente, sem enviar dados para nuvens.

Quais são os requisitos?

+
Windows 10 ou 11 (64 bits), PowerShell 5.1+ e Node.js 20+. O Ollama é opcional para funcionalidades de IA. Tudo isso gratuito e open source (licença MIT).

Funciona com Claude ou Copilot?

+
Sim! O servidor MCP nativo se integra com Claude Desktop e GitHub Copilot CLI. Também existe extensão para Chrome/Firefox e plugin para Notepad++.

Junte-se aos usuários que já automatizam a manutenção do Windows com segurança total.
