Instalação Rápida

A forma mais rápida de começar. Execute no PowerShell (como Administrador):

git clone https://github.com/jeanavila997-ux/Mestre-do-PC-V10.git
cd Mestre-do-PC-V10
.\ativar-atualizar-tudo.ps1
ℹ️ O que o script faz: baixa dependências, roda os testes, inicia o launcher e registra as tarefas agendadas.
🛠️

Modo Desenvolvedor

Para quem quer customizar a ferramenta ou contribuir:

  • 1 Clone o repositório do GitHub.
  • 2 Instale as dependências em /v10 e /mcp-server.
  • 3 Execute npm start em ambos os diretórios.
cd mcp-server && npm ci && npm test
cd ..\v10 && npm install && npm start

🔒 Verificação de Integridade

Após baixar, verifique o hash SHA256 do arquivo para garantir que ele não foi alterado:

Get-FileHash .\Mestre-do-PC-V10.zip -Algorithm SHA256
⚠️ Segurança: o launcher aceita apenas comandos cadastrados em allowed-operations.json. Leia o SECURITY.md antes de usar em computadores de produção.
