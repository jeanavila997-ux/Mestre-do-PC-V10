# Como contribuir

1. Crie uma branch a partir de `main`.
2. Faça alterações pequenas e documentadas.
3. Execute `npm ci && npm test` em `mcp-server`.
4. Execute `node --check v10/launcher.js`.
5. Não adicione comandos livres. Novas operações devem entrar no catálogo e receber revisão de segurança.
6. Abra um pull request descrevendo risco, efeito e forma de reversão.
