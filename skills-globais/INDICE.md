# Índice das Skills Globais

Atualizado: 2026-10-28 · Fonte: Microsoft Learn Edge DevTools

| ID | Nome (slug) | Categoria | Quando usar |
|---|---|---|---|
| 1 | `inspecionar-elementos` | Inspeção DOM | Ver/alterar DOM/CSS, achar seletor, snapshot a11y |
| 2 | `depurar-console` | Console JS | Erros JS, avaliar script, logs |
| 3 | `inspecionar-rede` | Rede | Requests, status, headers, XHR/fetch |
| 4 | `analisar-desempenho` | Desempenho | Lighthouse, trace, Core Web Vitals, cobertura |
| 5 | `testar-acessibilidade` | Acessibilidade | Contraste, alt, teclado, árvore a11y |
| 6 | `emular-dispositivos` | Emulação | Mobile, viewport, sensores |
| 7 | `auditar-seguranca-armazenamento` | Segurança | Cookies, storage, HTTPS, Service Worker |
| 8 | `conectar-navegador-agente` | Acesso agente | CDP, Edge remoto, chrome_*, limitações edge:// |

## Analogia

Pense no DevTools como uma **oficina**: Elementos = bancada de peças, Console = terminal da oficina, Rede = porta de entrada de materiais, Performance = cronômetro, A11y = checklist de segurança. As skills são o **manual de cada bancada** para o agente não improvisar.
